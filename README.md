# LumiMot · 法语光词 V2.0

一个轻量、离线可用、暖光护眼的法语教材背词 Web 应用，基于纯原生 HTML5 + CSS3 + JavaScript (ES6+) 构建。

## 核心功能

- **按课顺序背词**：完整内置《你好！法语》1 (A1) 全书 9 单元 36 课（939 词）及《北外法语》1 词库，支持按 `第1课 → 第36课` 顺次背诵与一键切换上下课。
- **艾宾浩斯记忆曲线（SRS）**：内置间隔重复算法、记忆保持率可视化曲线与 7 日复习预测。
- **标准法语 IPA 与语音朗读**：每个词条均配国际音标、例句（译文默认隐藏可按需展开）及动词现在时变位表，支持正常 / 慢速法语朗读。
- **专项强化**：阴阳性快刷模式 + 仅抽考已背单词的拼写测验（支持重音符号键盘与宽松判分）。
- **自定义词书与本地备份**：支持自由新建/编辑词书、批量导入与 JSON 导出备份，学习进度保存在浏览器 `localStorage`。

## 文件说明

- `index.html` — 应用主程序（含界面、样式、记忆曲线与交互逻辑）
- `nihao_a1_data.js` — 《你好！法语》1 (A1) 全 36 课完整词汇、IPA 音标与动词变位
- `textbooks_data.js` — 扩展教材词库（《北外法语》1 等）
